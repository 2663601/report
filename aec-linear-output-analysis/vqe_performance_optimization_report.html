2. AEC 优化（6项）

2.1 FilterAdaptation 隔帧更新

每2帧更新一次自适应滤波器权重，省 24次FFT → 12次。

效果：AEC -15% | 低风险：收敛变慢一倍，稳态不变

2.2 关闭 delay_logging

跳过 DelayEstimatorProcessFloat 和直方图统计。

效果：-3% | 无风险

2.3 关闭 metricsMode

跳过 UpdateLevel/UpdateMetrics 功率统计。

效果：-2% | 无风险

2.4 去除噪声功率估计

Comfort Noise 已关闭，噪声估计循环为死代码。

效果：-2% | 无风险

2.5 去除 abs_spectrum sqrtf

delay_logging 已关闭，129×2次 sqrtf 为死代码。

效果：-2% | 无风险

2.6 去除 cohxd2 + NLP qsort→partial select

单延时路径设备不需要双路相干；qsort 改为 O(k*n) 选择。

效果：-5% | 无风险（数学等价）

3. NS 优化（4项）

3.1 fast_expf 替换（含范围保护）

SpeechNoiseProb + NoiseEstimation 中 expf → 整数位操作近似。

static inline float ns_fast_expf(float x) {
    if (x < -87.0f) return 0.0f;
    if (x > 88.0f) return 3.4e38f;
    union { float f; int32_t i; } v;
    v.i = (int32_t)(12102203.0f * x + 1065353216.0f);
    return v.f;
}

效果：NS -8% | 无风险

3.2 SIMULT 3→2

噪声量化估计从3组并行减为2组，省1/3循环。

效果：NS -8% | 低风险

3.3 merge_aec FFT 场景自适应降频

核心创新：基于 AEC 的 hNlXdAvg 判断近端/回声状态，动态调整更新频率。

  • 回声段（hNlXdAvg < 0.9）：每帧更新，保证回声抑制
  • 近端单讲（持续50帧后）：每4帧更新一次，省75% FFT

效果：近端场景 NS -56% | 无风险（回声段不降频）

3.4 gainmap 能量补偿跳过

省 Energy(256) + sqrtf + factor 计算。

效果：NS -5% | 低风险

6. 关键经验

  1. 先 profile 定位瓶颈（AEC 64% + NS 32%），避免盲目优化
  2. 快速数学函数必须加范围保护（溢出→NaN→后续全部归零）
  3. 累积计算路径不能用近似函数（误差逐帧叠加失控）
  4. -ftree-vectorize 已自动向量化简单循环，手写NEON无额外收益
  5. 场景自适应策略优于固定降频（回声段保质量，安静段省性能）
  6. ARM 32-bit printf 不要混用 %f 和 %d（参数栈对齐问题）
