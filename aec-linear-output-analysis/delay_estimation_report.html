1.2 核心技术点

  • ewan MF 5-filter：时域自适应匹配滤波，降采样因子4，覆盖 5×384+512 = 2432 个降采样tap (≈608ms)，内置 histogram 聚合
  • WebRTC Binary Spectrum：频谱二值化 + 汉明距离互相关，history=500 blocks 覆盖 2000ms，极低延迟 (~5us)
  • 4-Feature Weighted Confidence：对 Binary 输出做多维验证，提升大延时场景可靠性
  • VAD Gating：所有特征计算跳过远端静音帧（但buffer保持时间对齐），避免无效数据污染
  • Direct Selection（无双重Histogram）：避免 Binary 自带 histogram 与外部 histogram 冲突
  • Binary → MF Guidance：Binary 高置信收敛后通过 SetDelayOffset 引导 MF 搜索范围（受 buffer 限制效果有限）

8. 后续优化方向

  1. 延时减小跟踪：检测延时突然减小(Binary新估计 < 当前延时的50%)时，快速 flush Binary histogram，重新累积
  2. 噪声鲁棒性：在高噪声 (SNR<5dB) 场景自动禁用 Binary 输出，或降低 Binary 在融合中的权重
  3. MF 边界保护：当延时在 MF 覆盖范围内(≤608ms)且 MF 曾收敛过，禁止 Binary 覆盖 MF 输出
  4. VQE 集成 hold-last：conf_count 曾达到高值(>100)后，即使当前 conf=0 也不阻塞延时校正
  5. Binary → MF Guidance 深度优化：解决 render buffer size 与 histogram aggregator 耦合问题
